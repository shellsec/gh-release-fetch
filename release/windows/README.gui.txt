GH Release Fetch 图形便携版

完整解压 ZIP，再双击 GHReleaseFetch.exe。程序自带运行环境。

在「平台目录」选平台和分类，可搜索名称、别名或仓库。单击方框勾选，
切换平台后保留勾选。点「批量下载」，附件按平台保存。右键可立即下载或打开官网。
「导入清单」支持旧版 saved_apps_*.json。右键队列任务可复制路径或查看任务日志。
设置、任务记录和 GUI 下载日志保存在程序目录的 catalog_downloads 子目录。
App Store 等页面入口会在默认浏览器打开。

「仓库与 Chrome 扩展」接受仓库、Release、附件链接或商店扩展 ID。
发布附件可多选。源码 ZIP 可保留或同时解压到同名目录。
Git 克隆需要系统有 Git，获取 LFS 文件还需要 Git LFS。

队列可暂停、继续或重试。退出后未完成的任务会保留，重开后可继续。
续传要求下载源支持 Range 且能提供相同的强 ETag。
文件变化或来源不支持安全续传时会重新下载。

下载任务不会自动运行安装包。可在队列中选任务后打开所在目录。
